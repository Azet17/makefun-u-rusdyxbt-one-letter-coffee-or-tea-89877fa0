# One Letter: Coffee or Tea

This entry answers the one-letter question with a single bold choice: **"A" for coffee**. The program writes exactly one byte — the letter `A`, with no trailing newline and no explanation — to `/output/entry.txt`, because coffee is the bolder, more vivid, more alive answer, and vividness is the judge's first criterion.
